通知怎麼來

通知走手機，不走 LINE。

很多人以為這是一個會在群組裡報明牌的 LINE 機器人。不是。LINE 只出現在最開始的三十秒，之後就退場。

1 · LINE

只做一件事：認出你是誰

加好友的當下帳號就建立完成，LINE 立刻把「開始使用」的連結和 8 碼登入碼傳給你。不用下載、不用設密碼、不用填 Email。換手機時在聊天室傳「登入」就能重拿一組。

2 · App

把 App 裝到手機桌面

CapitalGuard 是網頁應用程式（PWA），加入主畫面之後就像一般 App 一樣有圖示、全螢幕開啟。不經過 App Store，也不必手動更新。

3 · 推播

訊號進手機的通知中心

盤中訊號、盤後事件、每日評分報告，全部由瀏覽器的 Web Push 直接送進手機通知中心，鎖定畫面就看得到。不經 LINE，不另外收費。

所以你的 LINE 聊天室不會被洗版。加好友之後，官方帳號只會傳登入與帳號相關的訊息（例如你自己要的一組新登入碼）。股票的事一律走推播通知，一則都不會出現在 LINE 裡。我們也讀不到你的聊天內容，只取得你的 LINE 顯示名稱與識別碼。

常見問題

開始之前

加了 LINE 好友，會一直收到 LINE 訊息嗎？
不會。官方帳號只傳登入與帳號相關的訊息——加好友當下那一則，以及你自己在聊天室要求「登入」時的新登入碼。股票的分數、盤中訊號、盤後事件一則都不會傳進 LINE，全部走手機的推播通知。
需要下載 App 嗎？
不用。CapitalGuard 是網頁應用程式（PWA），用瀏覽器開啟後「加入主畫面」就能像 App 一樣使用。iPhone 需 iOS 16.4 以上並加入主畫面，才能收到推播。
用什麼登入？
加 LINE 官方帳號好友就會自動建立帳號，LINE 會立刻把登入連結與 8 碼登入碼傳給你，不需要設定密碼。我們只取得你的 LINE 顯示名稱與識別碼，不會讀取你的聊天內容。之後在聊天室傳「登入」或「換手機」，隨時可以重拿一組新的碼。
通知怎麼送到手機？
透過瀏覽器的 Web Push 直接推到手機通知中心，不經 LINE 訊息，不另外收費。通知分兩級：橘色代表關卡已經觸發（漲跌停、跌破支撐、觸及目標價），藍色代表接近關卡或量能變化。
為什麼一定要加 LINE 好友？
因為帳號與登入碼都由 LINE 官方帳號發送，這是唯一的註冊入口。好處是不必設密碼、不必填 Email，換手機時在聊天室傳「登入」就能重拿一組碼。LINE 只負責認證這一件事，收訊還是走手機推播。
免費版能用多久？
沒有期限。免費版有 3 檔自選股與 3 條進階訊號，盤中盤後通知、每日評分報告、持股損益、K 線都完整提供。
付費後可以取消嗎？
隨時可以。取消後服務保留到當期結束，下期不再扣款。當期月費不按比例退還，詳見退款政策。
這是投資建議嗎？
不是。CapitalGuard 是公開市場資料的整理與統計工具，所有分數、訊號、事件、篩選結果與 AI 說明都是資料計算的呈現，不對任何股票做買賣、持有或進出場的推介。本服務並非證券投資顧問事業，投資決策請自行判斷。
